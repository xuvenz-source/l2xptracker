# L2 XP Tracker

Independent, experimental Windows farming tracker for Lineage II C1. Reads visible system-chat pixels using local OCR. No injection, game memory reading, packet interception, client modification or automated game inputs.

## Project status

The existing v0.17 application is being migrated to this repository. A verified portable Windows release is not yet available here.

## Features

- Personal XP, SP, Adena and visible party loot tracking.
- In-game XP/hour and Adena/hour HUD, manual pause/resume and focus protection.
- OCR review, persistent session history, renaming, merging and CSV export.
- Local settings and session storage.

## Safety and privacy

Not affiliated with NCSoft or L2 Reborn. Obtain server staff approval before using the tracker. OCR may miss or misread messages. Never upload personal settings, session databases, logs or chat screenshots. Public visibility is not an open-source license; a project license has not yet been selected.
