# Colour tracking (v0.30)

Configure Reborn system messages: XP/SP magenta, Adena yellow, item acquisitions green and consumable usage sky blue. Exact in-game configuration: XP/SP `#FF00FF` (255,0,255), Adena `#FFFF00` (255,255,0), items `#00FF00` (0,255,0), consumables `#00AAFF` (0,170,255). The colour filters tolerate rendered pixel variations, including observed screenshot RGB (255,13,255), (255,255,13), (13,255,13), and (13,194,255). Existing beige/yellow clients retain legacy OCR fallback. Use the Reviews category filters to correct uncertain messages, including unreadable colour-classified rows.

Consumable counts represent observed use messages (one activation per message), not necessarily inventory units. Enable/disable notices and ordinary skill messages are not usage. History and CSV retain separate consumable event types. The tracker cannot recover messages that scroll past between captures or distinguish identical frames with no detectable scroll. No game process memory or network inspection is used.

## v0.31 settings

Settings → Game capture → Text size: Small 16 px, Medium 17 px, Large 18 px (measured from supplied screenshots), or Manual 10–40 px. Rebind chat after changing the in-game font if the row alignment changes. Under In-game system message colours, use L2 defaults (Adena/items #FFFF00; all other messages #B09B79), Distinct colours (XP #FF00FF; Adena #FFFF00; items #00FF00; consumables #00AAFF; other #B09B79), or enter/pick any valid hex per category. Apply saves settings locally. Changes are applied at the next session. Shared colours are classified by text rather than guessed from hue; unclear shared-colour rows may require manual review. Distinct colours are recommended for best accuracy. Very dark colours and similar colours against the game background can be difficult to isolate.
