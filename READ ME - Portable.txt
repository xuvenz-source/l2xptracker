L2 LEGACY FARMING TRACKER — WINDOWS x64 PORTABLE

1. Extract the ENTIRE ZIP into a dedicated writable folder.
2. Run L2 Legacy Tracker.exe. Keep _internal and ocr beside the executable.
3. Bind visible in-game system chat and start a session.

No separate Python or Tesseract install is needed. Settings and session history
are stored in %LOCALAPPDATA%\L2LegacyTracker, outside the installation folder.
The application is unsigned. Verify its origin and obtain server staff approval.
It reads visible pixels using local OCR; no injection, game memory reading,
network interception, client changes or automated inputs.

WORKSPACE (v0.54 — Prestige)
Overview: live farming metrics and level progress.
Progression: XP/SP and next-level estimates.
Loot & Adena: item prices, expenses and desired drops.
Monster Library: active monsters and default kill assignment; Apply selection.
Party: members and presets. History: folders, merging, corrections and exports.
Reviews: correct OCR or monster identification. Activity Log: capture messages.
Settings: Tracking, HUD, Player status, Appearance, Updates and Advanced.

HUD
Main controls include Pause/Resume, Reset, lock and settings. Tracker visibility
is in the main gear menu. XP/SP and Adena/Loot have their own toolbar and gear.
Double-click a padlock to unlock, drag the panel, click to lock. Keep overlays
away from bound chat and status areas. Hiding a tracker does not pause capture.

TRACKING
Use windowed/borderless mode and visible, unobstructed chat. The timer continues
on focus loss by default; capture still needs visible pixels. Enable pause on
focus loss if desired. Stop waits for queued OCR; Reset saves the previous session.
Personal reward messages are a kill proxy; missed/non-kill messages affect rates.
Default monster assignments and party estimates are assumptions, not proof.
Unpriced consumable uses are marked; drop waits are statistical averages.

UPDATES
Automatic installation is enabled by default and waits until idle. The updater
checks published releases on startup and every 30 minutes, verifies downloads
and restarts the tracker. Launch only the main executable. Use Settings > Updates
for preferences and backups. Compatible installs use direct incremental patches.

SUPPORT
Settings > Advanced provides diagnostics and optional OCR evidence collection.
Do not share private chat or personal session data without reviewing it first.
Automated build checks do not verify live gameplay or clean-PC compatibility.
