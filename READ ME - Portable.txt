L2 LEGACY FARMING TRACKER v0.35.1 — WINDOWS x64 PORTABLE

1. Extract the ENTIRE ZIP to a normal folder (not directly inside the ZIP viewer).
2. Double-click L2 Legacy Tracker.exe.
3. Bind your game/chat area once and start tracking.

No Python, pip or separate Tesseract installation is required on the recipient's PC.
Keep the _internal and ocr directories beside the EXE. Do not send the EXE alone.
The tracker runs locally and requires no account or network connection for OCR.
Settings and session history are kept in %LOCALAPPDATA%\L2LegacyTracker, not inside
this folder. The package does not contain the builder's personal data.

Includes v0.29 session history and merging, review queue, pause/resume, HUD,
window-focus checks and the existing OCR logic. The external HUD works best in
windowed or borderless mode. It does not inject, read game memory, intercept
packets or send automated input. Obtain server staff approval before use.

This is an unsigned community tool. Verify its origin before running it. If a
security product blocks it, do not disable protection; investigate first.
The build self-test validates bundled OCR, Tcl/Tk, SQLite and MSS initialization,
not actual gameplay. Test on another clean Windows PC before distribution.

Party setup: enter other character names before Start. Visible drops are recorded;
party Adena estimates assume equal shares and are not actual loot. Stop and
start a new session if party membership changes.

Kills/hour uses personal XP acquisition messages, one kill per recorded event.
Non-kill XP and missed messages can affect this estimate.

Updates: checks published releases on launch or via Check for updates. Approve
installation when not tracking. Use a dedicated app folder with no extra files.
The previous installation is kept as a backup; settings/history are separate.

Reviews: select XP / SP or Adena and enter numbers. Already-counted values are
locked; use Item / other for item loot. Confirm the recipient for Adena.

Appearance: dark mode is enabled by default. Use Settings to enable Light mode.
The choice is remembered independently of your calibration and sessions.

HUD Pause/Resume controls manual tracking. Settings includes pause on focus loss
(off by default). Background capture requires visible, unobstructed game chat.

Automatic installation is on by default; change it in Settings. Checks run on
startup and every 30 minutes. Installs wait until idle and restart the app.
Launch only L2 Legacy Tracker.exe; the bundled helper is invoked internally.

Session history: merged sessions are collapsed parent groups. Expand to see
original sessions and nested merged reports. Corrections update every parent.

Party setup: save named presets, load recurring teammates and choose Use party.
Preset edits never change recorded session rosters.

The main window uses tabs. Starting with v0.29, compatible smaller incremental
patches reuse verified local files; full packages remain the fallback.

Capture/pause hotfix: keep focused game chat unobstructed. If issues remain,
Settings > Open diagnostic folder opens tracker-diagnostics.log and tracker-crash.log.

History supports drag-and-drop grouping; existing memberships are preserved.

HUD movement (v0.32): double-click the top-right padlock to unlock; left-click and drag the HUD body; single-click the open padlock to lock. Pause/Resume works in either state. The HUD starts locked each launch.

HUD opacity (v0.33): Settings → Tracking → HUD opacity. Choose 20–100%; Reset returns to 92%. Saved automatically; return to the foreground game to see the new opacity.

Consumable costs (v0.34): double-click a Dashboard consumable to enter Adena per observed activation. Set default cost preconfigures future sessions. History retains each original session's prices. Unpriced uses are marked, not assumed free. Separate consumable CSV is included in exports.

HUD net Adena (v0.35): Settings → Tracking → Subtract consumable costs from HUD Adena/hr (net). Replaces gross HUD rate with net of known costs; * marks unpriced uses. Default off; saves automatically.

HUD drag hotfix (v0.35.1): native mouse movement and capture support unlocked dragging even when asynchronous button polling is unreliable. Drag outside the selected chat area; local diagnostics record drag lifecycle.
